### 1. Git-хэш фиксирует грязное дерево

`run_meta.py:31` пишет `git rev-parse HEAD` без проверки состояния рабочего дерева. Хэш в `run.yaml` может указывать на коммит, отличный от исполнявшегося.

```python
def git_state() -> dict:
    """hash + dirty + список изменённых файлов.

    Без этого run.yaml утверждает воспроизводимость, которой нет.
    """
    return {"hash": ..., "dirty": bool(porcelain), "changed": porcelain_files[:20]}
```

Обратная совместимость: ключ `git_hash` в `run.yaml` сохранить, добавить `git_dirty` и `git_changed`.
