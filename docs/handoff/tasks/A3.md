## Что сделать

### 1. Расширить `Prediction`

```python
class Prediction(BaseModel):
    id: str
    faithfulness_pred: int = Field(ge=0, le=1)
    relevance_pred: int = Field(ge=0, le=1)
    marker_pred: str | None = None
    raw_output: str | None = None
    invalid_output: bool = False
    faithfulness_prob: float | None = Field(default=None, ge=0, le=1)
    relevance_prob: float | None = Field(default=None, ge=0, le=1)
    prob_method: str | None = None
    # NEW
    scores: dict[str, float] = Field(default_factory=dict)

    @field_validator("scores")
    @classmethod
    def _score_keys(cls, v):
        """Ключ обязан быть '<метод>.<сигнал>' — стэкер собирает фичи по префиксу
        и должен падать на коллизиях, а не молча их склеивать."""
        bad = [k for k in v if "." not in k or k.startswith(".") or k.endswith(".")]
        if bad:
            raise ValueError(f"score keys must be '<method>.<signal>', got {bad[:5]}")
        return v
```

Закреплённые префиксы: `surf.`, `m3.`, `m6.`, `enc.`, `ld.`, `stack.`, `ind.`

Обратная совместимость обязательна: существующие 22 файла предсказаний должны читаться без изменений (у них нет ключа `scores` — сработает `default_factory`).

Это ключевой механизм требования Т1: отчёт **физически** не сериализуется без ДИ.

### 3. `scripts/migrate_predictions.py`

Одноразовый скрипт. Что делает:

- обходит `predictions/**/{val,test,train}.jsonl`;
- переносит `p_faith` → `scores["<prefix>.p_faith"]`, `p_rel` → `scores["<prefix>.p_rel"]`, сохраняя исходные поля;
- определяет префикс по пути: `local/baselines/surface` → `surf`, `alfa_openrouter/m3/*` → `m3`, `cloud/m6` → `m6`;
- склеивает val+test (и train, если есть) в один `scores.jsonl` рядом;
- **не достраивает недостающие строки.** Если суммарно меньше 2233 — в `run.yaml` дописывается `partial: true` и фактическое `n`;
- идемпотентен: повторный запуск не дублирует строки и не портит уже мигрированное.

```bash
python scripts/migrate_predictions.py --root predictions --dry-run
python scripts/migrate_predictions.py --root predictions
```

`--dry-run` печатает таблицу «путь → префикс → n строк → partial?» без записи.
