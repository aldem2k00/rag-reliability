# C1 — Стэкинг разнородных сигналов

**Волна 3** · ветка `task/C1-stacking` · база `integration` (после B1) · спека `docs/specs/20_PHASE1_быстрые_победы.md` §1
**Зависимости:** B1 (`evaluate_cv`), A2 (`bootstrap`). **Блокирует:** D4.

Самая дешёвая задача с измеренным эффектом. Никаких новых вызовов моделей — только уже закоммиченные артефакты.

---

## Основание

Измерено на существующих `predictions/**`, 5×5-fold CV на 446 размеченных кейсах:

| Набор сигналов | ROC-AUC | macro-F1 |
|---|---:|---:|
| только surface (2 фичи) | 0.6218 ± 0.0021 | 0.5798 ± 0.0035 |
| только M3 zero-shot (2 фичи) | 0.5657 ± 0.0044 | 0.5794 ± 0.0035 |
| **surface + `m3.p_faith`** | **0.6277 ± 0.0035** | **0.6085 ± 0.0066** |
| surface + обе оси судьи | 0.6276 ± 0.0027 | 0.6077 ± 0.0060 |
| все 8 сигналов | 0.6199 ± 0.0033 | 0.6160 ± 0.0117 |

Честный вариант (обучение на val, применение к test): **0.6205** против лучшего опубликованного 0.5982.

Два вывода, определяющие дизайн:

- **`m3.p_rel` не добавляет ничего** (0.6085 → 0.6077); его AUC = 0.497. В базовый набор не включать.
- **На 8 фичах AUC падает** — переобучение. Литература по калибровке панелей при конечном бюджете меток рекомендует скалярную агрегацию, а не joint-table (выигрывает в 16 из 20 ячеек). Держать 5–7 фич.

### 3. `scripts/run_stack.py`

```bash

  --data data/organizers.jsonl --folds data/splits/folds.json \
  --sources surf=predictions/alfa/baselines/surface/scores.jsonl \
            m3=predictions/alfa/m3_judge/zero_shot/scores.jsonl \
  --features surf.p_faith,surf.p_rel,m3.p_faith \
  --model logreg \
  --output predictions/stack/v1/
```

## Тесты

- `collect_features` падает при отсутствующем id с перечислением недостающих;
- `collect_features` падает при отсутствующем ключе;
- порядок строк соответствует `sample_ids`, а не порядку в файлах;
- `calibrate="auto"` выбирает Platt при n_train < 500 и isotonic при ≥ 500;
- `fit_stack` не имеет доступа к тестовым индексам (мок, записывающий переданные данные);
- **регресс на реальных артефактах:** стэк `surf.p_faith, surf.p_rel, m3.p_faith` на 446 доступных кейсах даёт macro-F1 ≈ 0.6085 (допуск 0.02) и AUC ≈ 0.6277 (допуск 0.02);
- `select_features_by_ci` не включает фичу с ДИ приращения, пересекающим ноль.
