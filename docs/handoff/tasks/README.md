## Что нужно GPU

Только для *запуска*, не для написания. Весь код пишется и тестируется на dummy-бэкендах.

| Задача | Пишется без GPU | Проверяется на реальных данных без GPU | GPU-ч на запуск |

| A1–A5, B1, B2, C1 | да | **да, полностью** | 0 |
| C2 энкодер | да | нет | ~10 (5-fold OOF) |
| C3 M3 | да | частично (20 кейсов через OpenRouter) | ~3 |
| C4 M6 | да | частично (NLI на CPU, ~50 кейсов) | ~2 |

| D4 отчётность | да | да | 0 |

## Правило приоритета при конфликте

Если карточка противоречит спецификации в `docs/specs/` — **прав спецификация**,
карточка описывает более узкий срез. Противоречие зафиксировать в PR.

Если карточка противоречит коду — **прав код** как источник фактов о текущем
состоянии, но карточка описывает целевое. Расхождение в номерах строк
(`file:line`) означает, что кто-то уже правил файл: перепроверить и указать в PR.
